# Translations Menu

Translations menu is similar to one that's present in Translator++ translation app. It presents the possible translations from multiple endpoints when empty translation textarea is selected.

## Usage

You can click the "+" button to enable a certain endpoint. If you don't have it configured in settings, or your translations languages are set improperly, it will alert you. You can use "-" to disable it.

By default, Google translation is enabled. There's probably no reason to turn it off, it's free and fast way to get a rough translation.

To insert the translation to the currently selected textarea, just click the translation. It will be inserted only if current textarea is empty.

Check [Settings Documentation](./settings.md) on how to configure endpoints.
